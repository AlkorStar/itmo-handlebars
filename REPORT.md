# Отчет по учебному проекту

## Цель работы

Разработать универсальный инструмент для рендеринга шаблонов из JSON-контекста с поддержкой нескольких шаблонизаторов и зафиксировать процесс разработки с помощью Codex.

## Текущее состояние проекта

Проект реализован в двух форматах:

1. **CLI-инструмент** для пакетного рендеринга шаблонов.
2. **Веб-песочница** для интерактивной проверки шаблонов через браузер.

## Реализованный функционал

### 1) CLI

- Поддержка аргументов: `--template`, `--context`, `--out`, `--engine`
- Доступные движки: `handlebars`, `pug`, `nunjucks`, `jinja2`
- Handlebars: рендер с `strict: true`
- Вывод результата в stdout или запись в файл
- Обработка типовых ошибок:
  - отсутствующие аргументы
  - отсутствующий файл шаблона/контекста
  - невалидный JSON
  - ошибка компиляции или рендера шаблона
  - неподдерживаемый движок

### 2) HTTP API и веб-интерфейс

**Бэкенд (`src/server.js`):**
- `GET /` — страница песочницы
- `GET /api/engines` — список доступных шаблонизаторов
- `POST /api/render` — рендер шаблона (принимает `template`, `context`, `engine`)
- Лимит тела запроса: 1 MB

**Фронтенд (`public/app.jsx` на React):**
- Выбор шаблонизатора из выпадающего списка
- Редактор шаблона с подсказками синтаксиса для каждого движка
- JSON-редактор контекста с валидацией
- Отправка на бэкенд с отображением времени выполнения
- Кнопка копирования результата в буфер обмена
- Адаптивный дизайн с кастомными анимациями

## Архитектура

- `src/renderer.js` — общая логика рендеринга для всех движков, используется CLI и сервером
- `bin/hbs-runner.js` — CLI-запуск и обработка ошибок уровня командной строки
- `src/server.js` — HTTP-сервер, статические файлы и API эндпоинты
- `public/app.jsx` — React-компонент песочницы с состоянием и запросами к API

**Ключевое архитектурное решение:** единая функция `renderTemplateFromSource()` обслуживает и CLI, и API, и веб-песочницу.

## Технологический стек

- **Node.js** — рантайм
- **Handlebars** (`^4.7.9`) — основной шаблонизатор
- **Pug** (`^3.0.4`) — альтернативный шаблонизатор
- **Nunjucks** (`^3.2.4`) — альтернативный шаблонизатор
- **React 18** — фронтенд (UMD + CDN, без сборки)
- **Babel Standalone** — транспиляция JSX в браузере
- **Vitest** (`^1.6.0`) — тестирование
- **CommonJS** — основной код проекта

## Проверка корректности

**Критерии корректности:**
- корректный рендер простых и вложенных полей для всех движков
- поддержка циклов (`each` в Handlebars, `each item in items` в Pug, `for` в Nunjucks)
- корректная обработка ошибок (CLI exit code 1, API с полем `error`)
- прохождение автоматических тестов

**Результат:** `npm test` проходит успешно (5 тестов из 5).

**Дополнительная проверка:** веб-песочница позволяет вручную тестировать все 4 движка с отображением времени выполнения.

## Ограничения и возможные улучшения

**Текущие ограничения:**
- Фронтенд использует Babel в браузере (учебный вариант, не для production)
- Лимит тела запроса API — 1 MB
- Нет поддержки partials и кастомных хелперов
- Нет кэширования скомпилированных шаблонов

**Возможные улучшения:**
- переход на Vite/webpack-сборку React для production
- добавление кэширования шаблонов для повышения производительности
- расширение API (поддержка partials, хелперов, пользовательских настроек)
- добавление e2e-тестов для веб-песочницы (Playwright/Cypress)
- поддержка загрузки файлов через веб-интерфейс
